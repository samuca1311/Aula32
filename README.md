# Aula32 — Eventos em JavaScript

Atividade prática: Painel de Controle Interativo, feito com HTML, CSS e JavaScript básico, sem bibliotecas.

## Como abrir

Baixe o repositório e abra o arquivo `index.html` no navegador. Mantenha `style.css` e `script.js` na mesma pasta.

## Como testar

1. Clique na caixa: a cor alterna entre azul e verde.
2. Entre e saia da caixa com o mouse: o texto muda para “Mouse está aqui!” e volta para “Clique aqui!”.
3. Digite no campo: a última tecla pressionada aparece na tela.
4. Pressione Enter: o texto é adicionado à lista de envios e o campo é limpo.
5. Clique em Incrementar e Decrementar para alterar o contador.
6. Pressione as setas para cima e para baixo: o contador também muda, inclusive com o campo de texto selecionado.

Todos os eventos são registrados com `addEventListener()` no arquivo `script.js`.
